📌 Project Overview
-------------------

The **Paragon Apartment Management System (PAMS)** is a group project developed by 5 students at **UWE Bristol**.

It is an apartment management system that improves how apartments are managed. It replaces manual processes with a secure, centralised digital platform. It supports multiple locations and role-based access for staff, managers, and tenants.

The system was developed using **Python (Tkinter)** and **SQLite**, following a structured process of planning, design, development, and testing.
