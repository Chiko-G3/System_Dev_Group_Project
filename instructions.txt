Paragon Apartment Management System (PAMS)


1. Clone the Repository First

git clone https://github.com/MohamedHamouda23/software_dev-Paragon-Apartment-Management.git

--------------------------------------------------

2. First-Time Setup

Navigate to the system folder first:

cd software_dev-Paragon-Apartment-Management/system

Install Required Packages

macOS:
pip3 install reportlab pytest tkcalendar

Windows:
pip install reportlab pytest tkcalendar
--------------------------------------------------

3. Setup Database

Before running the system, initialize the database using the schema file.

macOS / Linux:
cd database
sqlite3 database.db < schema.sql
cd ..

Windows (Command Prompt):
cd database
sqlite3 database.db < schema.sql
cd ..

--------------------------------------------------

4. Run the System

Make sure you are inside the system folder:

cd software_dev-Paragon-Apartment-Management/system

macOS:
python3 -m main.index

Windows:
py -m main.index
or
python -m main.index

--------------------------------------------------

5. How to Use

- Run the system
- Login using credentials
- Access modules based on your role
